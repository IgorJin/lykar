Архитектура проверенного потока

Editor открывает about:blank синхронно внутри клика, затем заменяет URL после API-ответа. Bridge загружает remote operations, читает local pending до replay и хранит capability только для совпадающих API/origin/path.

Найденные дефекты и исправления

РискПричинаИсправление и regression
Изолированный E2E мог взять рабочий DB URL.Наследовались LYKAR_E2E_DATABASE_URL и другие env.scripts/e2e-process.mjs разделяет isolated/dev режимы; тест с несуществующим URL прошёл на временной БД.
Popup test не проверял реальную блокировку.Chromium запускался с Playwright default --disable-popup-blocking.playwright.config.ts убирает только этот аргумент, а infrastructure test ждёт console event и подтверждает blocked delayed popup. Реальный Admin click остаётся рабочим.
Capability могла отправить token в другой API.Restore переписывал persisted API URL настроенным URL.packages/editor-bridge/src/access-client.ts проверяет exact API, page path, expiry и revision; invalid storage fail-closed.
Reload терял local pending edit.Remote replay очищал тот же storage до чтения pending.packages/editor-bridge/src/session.ts читает pending до remote replay, дедуплицирует ids, сохраняет committed/pending history; есть Undo/Redo regression.
Поздний draft GET менял уничтоженный editor.Async ответ не был связан с lifecycle.packages/editor-bridge/src/editor.ts использует AbortController и active checks; late-response test не меняет DOM.
Cleanup мог оставить descendants.Фиксированная задержка вместо ожидания graceful exit.scripts/e2e-process.mjs ждёт exit, затем ограниченно применяет SIGKILL; отдельные lifecycle tests проверяют parent/process-group cleanup.
