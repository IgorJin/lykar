Архитектура запуска

Изоляция

Browser mode выбирает четыре свободных порта, создаёт временный каталог и PostgreSQL cluster, затем удаляет их в global teardown.

Два режима auth

Основной API включает безопасный локальный dev login. Второй API работает без него и пишет magic links в закрытый временный NDJSON-файл.

Артефакты

При падении Playwright сохраняет screenshot, trace, video, error context и HTML report. Каталоги исключены из Git.
