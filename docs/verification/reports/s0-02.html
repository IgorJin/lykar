Архитектура проверки

Корневой оркестратор

package.json вызывает scripts каждого workspace с --if-present. Отчёт отдельно инвентаризирует отсутствующие scripts.

Последовательность

Build выполнен первым, затем статическая проверка, затем тесты. Каждая команда завершилась самостоятельно с кодом 0.

Integration boundary

Три теста API требуют LYKAR_TEST_DATABASE_URL. Их SKIP ожидаем в этом этапе и закрываем реальной временной БД в S0-03.
