Архитектура пользовательских путей

Popup correctness

Тест нажимает UI-кнопку и ждёт событие новой страницы. Прямого вызова editor-launch нет, поэтому проверяется реальное browser popup permission.

Magic link

Токен доставляется через существующий sender в временный файл с mode 0600. Browser открывает ссылку в том же context.

Shadow DOM

Готовность редактора определяется видимыми heading и status внутри открытого Shadow DOM, а не размером пустого host element.
