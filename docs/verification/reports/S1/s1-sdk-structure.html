Главное структурное изменение

Оркестрация доступа больше не живёт в playground. Страница подключает публичный SDK, а SDK выбирает режим и загружает editor только после успешного capability exchange.

script / npm
      │
      ▼
@lykar/sdk ── access selector ──┬── native (без network)
                                ├── visitor / variant / experiment → runtime
                                ├── share → runtime (read-only)
                                └── editor → capability → lazy editor bridge

Что добавилось и что переместилось

Новый публичный слой

  • packages/sdk/src/index.ts — exports и facade.
  • packages/sdk/src/sdk.ts — lifecycle start/refresh/navigate/destroy.
  • packages/sdk/src/access.ts — access exchange, selectors, URL cleanup.
  • packages/sdk/src/types.ts — public modes, diagnostics и callbacks.

Script entry

  • packages/sdk/src/global.ts выставляет window.Lykar.
  • Обычный script в links-only не делает manifest request.
  • Конструктор безопасен для SSR: нет DOM mutation и network request.

Playground boundary

  • playground.js оставлен UI/config adapter.
  • Launch/share orchestration удалена из host fixture.
  • Editor asset приходит через SDK по lazy path.
