Network и host safety

  • Обычный native links-only visit не делает network request и не загружает editor.
  • Явные visitor/editor/share requests ограничены network timeout 5 секунд по умолчанию.
  • Timeout, 401/403/404 и lazy-load failure дают native/error result, не скрывая host page.
  • Browser E2E: 6/6; HTTP E2E: 21 API tests + smoke.
