Новая граница поставки

@lykar/sdk теперь является самостоятельным package artifact. Rollup собирает публичный ESM и IIFE entry, declarations и source maps. Editor bridge копируется в отдельный lazy asset и не входит в visitor orchestration.

Versioning model

  • SDK/package version: 0.0.0.
  • Runtime, editor и protocol versions записываются отдельно.
  • Stable names получают versioned copies: sdk-0.0.0.esm.js, sdk-0.0.0.iife.js, editor-0.0.0.iife.js.
  • Page Release version остаётся внешним измерением и не смешивается с package/protocol version.
