Архитектура проверяемого стенда

Dev data

`dev:e2e` хранит cluster в .lykar/e2e, повторяет migrations и idempotent seed. Это удобный рабочий стенд, а не тестовая fixture.

Test data

HTTP и browser commands используют случайные порты и новый temporary cluster. Поэтому результат не зависит от прежних ручных данных.

Граница доступа

Dev login доступен только development API на loopback. Editor bearer scoped по Draft/Page, share context получает отдельный runtime access.
