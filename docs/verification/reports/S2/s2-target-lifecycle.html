Итоговый контракт

Release адресует immutable logical targets, strict resolver допускает мутацию только при одном кандидате, а PageSession выдаёт право на side effects только текущему поколению страницы и root.

Release → frozen binding → strict target resolution
                              │
PageSession(project/page/root/generation)
  ├─ AbortController → fetch / readiness / retry / editor
  ├─ guard → mutation / storage / URL / report / event
  └─ cleanup → listeners / RAF / overlay / pending work / journal hook

Target identity

  • Stable project/page/root scope.
  • Versioned environment bindings.
  • Legacy descriptor replay без переписывания Release.

Strict replay

  • unique / missing / ambiguous / invalid.
  • Before/desired state и structural drift policy.
  • Bounded repair evidence без DOM references.

Async ownership

  • Concurrent start объединён; replay сериализован.
  • A→B late transport не мутирует и не сообщает report.
  • Root/draft isolation и idempotent cleanup.
