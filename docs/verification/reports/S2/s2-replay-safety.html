Итоговый контракт

Replay адресует созданные elements и text nodes через serializable identity, выполняет только доступные dependency chains и компенсирует принадлежащие PageSession mutations, не затирая более позднее состояние host.

validate bytes / count / depth / unsafe payload

                    ├─ nodeRef → scoped ReplayLedger → exact Node
                    ├─ mutation → before/after journal → result
                    └─ independent operation continues
                                      │
timeout / PageSession destroy ────────┴─ reverse compare-and-restore
                                           ├─ unchanged → COMPENSATED
                                           └─ host changed → preserve + reload guidance

S2-03.1 · Identity

  • Scope: project/page/release/draft/generation/operation/path.
  • Element attributes и comment markers для text nodes.
  • Forced replay не создаёт duplicate insertion.

S2-03.2 · Dependencies

  • Только earlier explicit prerequisites.
  • nodeRef не использует locator fallback.
  • Независимые operations продолжаются после skip/error.

S2-03.3 · Journal

  • Scalar before/after evidence; closures только in-memory.
  • Reverse compensation для text/style/attribute/insert/move/remove.
  • Host mutation сохраняется с diagnostic.

S2-03.4 · Bounds

  • 512 KiB, 1,000 ops, depth 32, 5,000 serialized nodes.
  • Replay/retry limits и root-scoped observer.
  • Unsafe payload отклоняется до первой mutation.
