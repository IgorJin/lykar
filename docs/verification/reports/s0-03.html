Архитектура стенда

Два режима данных

Smoke создаёт временный cluster и всегда удаляет его. Dev-режим хранит .lykar/e2e, чтобы повторный seed сохранял drafts и releases.

Владение ресурсами

PostgreSQL останавливается только когда текущий запуск действительно его стартовал. Уже работающий cluster проверяется на ожидаемом порту и не присваивается.

Fail fast

API и playground порты проверяются до миграций и сборки. EADDRINUSE сообщает точный порт и переменную окружения.
