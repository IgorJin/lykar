Аккордеоны / Details

Что это за страница?

Один HTML-файл, который покрывает распространённые кейсы редактирования UI на «живом» DOM. Проверь работу DropPolicy и Overlay.

Как лучше навешивать селекторы?

Используй data-lykar-* или устойчивые классы. Для key-патчей храни родителя + соседа + позицию (before/after/inside).
